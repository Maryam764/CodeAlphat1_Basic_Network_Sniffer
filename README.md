
# Basic Network Sniffer

## Project Description
This is a beginner-level Python project that captures network packets and displays basic packet information.

## Features
- Captures network packets.
- Displays source IP address.
- Displays destination IP address.
- Identifies protocols such as TCP, UDP, and ICMP.

## Technologies Used
- Python
- Socket Library

## How to Run
1. Install Python.
2. Open the project in PyCharm.
3. Run PyCharm as Administrator.
4. Run network_sniffer.py.
5. Press CTRL + C to stop the program.

## Learning Outcomes
- Understanding network packets.
- Learning IP addresses.
- Understanding TCP, UDP, and ICMP protocols.
